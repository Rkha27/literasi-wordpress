Nova Architecture is a modern WordPress theme for architecture firms, architects, architectural studios, and building design professionals. Its clean and elegant design helps showcase architectural projects, creative portfolios, professional services, and completed buildings. Ideal for residential architecture, commercial architecture, contemporary design studios, and architectural visualization portfolios.

== Description ==

Nova Architecture is designed for architecture professionals who want to present their work through a clean, modern, and professional website. Its architecture-focused presentation helps highlight building projects, architectural concepts, project photography, and studio services.

The theme is suitable for architecture firms, independent architects, building designers, architectural consultants, and creative studios. It provides a foundation for presenting portfolios, sharing articles, introducing a team, and communicating with potential clients.

Nova Architecture is built as a child theme of Sima Architecture Interior and inherits its parent theme's templates and functionality while providing its own design customizations.

Features include:

Architecture-focused design customization
Portfolio and project presentation
Responsive layouts for mobile, tablet, and desktop
Custom logo and menu support
Featured image support
Blog and content layouts
Translation-ready structure
RTL language support

== Installation ==

Install and activate the Sima Architecture Interior parent theme.
In your WordPress dashboard, go to Appearance > Themes > Add New Theme.
Click Upload Theme and select the Nova Architecture ZIP file.
Install and activate Nova Architecture.

== Frequently Asked Questions ==

= Does Nova Architecture require another theme? =

Yes. Nova Architecture is a child theme and requires Sima Architecture Interior to be installed.

= Who is this theme designed for? =

It is designed for architecture firms, architects, building designers, architectural studios, and professionals who want to showcase architectural projects and portfolios.

= Does the theme support mobile devices? =

The child theme inherits the parent theme's responsive foundation. Its customizations should be tested across mobile, tablet, and desktop screen sizes.

= Can I customize the design? =

Yes. You can extend the child theme's CSS and use the customization options provided by the parent theme.
