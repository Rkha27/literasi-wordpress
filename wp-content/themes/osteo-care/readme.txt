A modern, responsive, block-based WordPress Full Site Editing theme designed for osteopathy, physiotherapy, medical clinics, wellness practices, and healthcare professionals.

== Description ==

Osteo Care is an elegant, full-site editing (FSE) block theme designed for osteopaths, physiotherapy clinics, medical practitioners, wellness centers, and holistic healthcare practices. Built from the ground up to utilize the WordPress Block Editor and Site Editor, Osteo Care provides customizable templates, clean typography, dynamic color palette controls, and mobile-optimized layouts.

== Guide ==

=== Folder Structure ===

- assets/     - Theme CSS, JS, fonts, and images.
- inc/        - Theme setup, registers, enqueue scripts, and admin settings.
- parts/      - Block template parts (Header, Footer).
- patterns/   - Block patterns for hero, about, treatments, team, why us, and testimonials.
- templates/  - Full Site Editing block templates (Front Page, Index, Page, Single, 404, Search, Archive).
- functions.php - Theme bootstrap file.
- index.php     - Fallback silence file.
- style.css     - Theme stylesheet and metadata header.
- theme.json    - Global styles, palette tokens, typography, and spacing settings.
- readme.txt    - Theme documentation and licensing.
- screenshot.png - Theme preview screenshot.
